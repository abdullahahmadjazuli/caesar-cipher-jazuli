# Caesar Cipher

Aplikasi web untuk enkripsi dan dekripsi Caesar Cipher dengan kunci pergeseran 0–25.

## Fitur
- Enkripsi
- Dekripsi
- Antarmuka web sederhana
- Tombol salin hasil
- Tanpa library/dependency eksternal

## Cara Menjalankan
Buka `index.html` langsung di browser.

## Tujuan
Project ini dibuat sebagai tugas mata kuliah Kriptografi untuk memahami implementasi cipher klasik.
